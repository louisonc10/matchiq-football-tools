# Contributing to MATCHIQ Football Tools

Thanks for taking the time to contribute.

MATCHIQ Football Tools is still a small project, so contributions should stay focused, easy to review and clearly explained.

## Ways to contribute

You can help by:

- reporting bugs
- suggesting improvements
- proposing new football sources
- suggesting changes to source ratings
- improving documentation
- adding tests
- improving source matching
- proposing new output formats

## Before opening a pull request

Please make sure:

- the change has a clear purpose
- existing behaviour is not broken
- tests still pass
- new behaviour is covered by tests where practical
- source rating changes include a reason

Run the test suite with:

```bash
python -m unittest discover -s tests -v
